# AI/ML Learning Projects

A collection of small AI and machine-learning projects created while learning new concepts, implementing models and experimenting with different approaches.

## Projects

### [Pattern Classification](./Pattern_Classification.ipynb)

Explores linear classification, kernel regression, support vector machines, manual backpropagation, and convolutional neural networks for image classification.

### [OMP Implementation](./OMP.ipynb)

Implements Orthogonal Matching Pursuit for sparse column selection, exploring how sparsity and noise affect reconstruction error and support recovery, with a comparison to ordinary least squares.

More projects will be added as I continue learning.
